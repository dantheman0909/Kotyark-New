# Kotyark Website: Wix Studio front-end kit (branch `claude/wix-studio-frontend`)

This branch has **no custom CMS**. Wix keeps managing content, files, documents and publishing.
The repo provides two things:

1. **`src/`**: the Next.js site, kept as the **visual reference** (design source of truth). It runs
   (`npm run dev`, port 5000) but is not what goes live.
2. **`wix/`**: the **Wix Studio kit** that carries that design onto the Wix-hosted site:
   - `wix/src/styles/global.css`: design system as Wix custom classes + Wix global/semantic classes.
   - `wix/src/public/custom-elements/*.js`: vanilla Web Components for the few interactive pieces.
   - `wix/src/public/pages/*.js`: Velo page logic; each Wix page file imports one init function.
   - `wix/data/collections/*.csv`: Wix CMS collection imports (investor sections, documents, SEBI table).
   - `wix/docs/`: page build spec, class catalog, CMS schema, custom elements, sync and publish guide.
   - `wix/reference/`: screenshots of the reference site, desktop and mobile.

## Wix constraints (verified against dev.wix.com, Oct 2026)
- Git integration repo layout: `wix.config.json` + `src/{pages,backend,public,styles}`. Files at the root of
  `src` are ignored. **Page code files are generated by Wix when a page is created in the editor; never
  create or rename them by hand.** That is why page logic lives in `public/pages/` and page files only import it.
- Import paths are Wix-style: `import { x } from 'public/pages/home'`, `'backend/...'`. Relative paths don't work.
- `global.css` (`src/styles/global.css`) styles elements through **classes only**: Wix global/semantic classes
  (`.button`, `.button__label`, …) and custom classes assigned in the editor's CSS Classes panel or with
  `$w('#id').customClassList.add()`. Theme variables: `var(--wst-…)`.
- Custom elements: standard `customElements.define()` classes in `public/custom-elements/`; **no Velo APIs inside**.
  Premium plan + own domain + no Wix ads required. Content is client-rendered: put SEO-relevant text in native
  Wix elements, or fill the element's SEO markup.
- Investor documents must stay native (repeaters bound to CMS collections) so Wix SSR, sitemap and search index them.

## Rules
- Copy text verbatim from the reference site. Never invent URLs, titles or dates.
- No secrets in the repo. Never print `DATABASE_URL` (a Claude cloud shell may export another project's).
- Scratch output goes in `attached_assets/_scratch/` (gitignored).

## Sub-agent routing
`.claude/settings.json` defaults sub-agents to Sonnet; `.claude/agents/*.md` pin roles
(Plan/code-reviewer = Opus; Explore/verifier/seo-checker = Haiku). Opus is for judgment, not labour.
